# README media

- `update-en.png` and `update-tr.png` show the actual v1.2.5 WPF Update interface at 2× resolution.
- `interface-demo.gif` is a 20-second looping interface walkthrough: selection, then Update → Delete → Patch → Backup → Update.

Captured on 3 October 2026, Europe/Istanbul, from the repository presentation code. The capture harness rendered the interface without launching first-run setup or maintenance. It used the app's registry scanner, GitHub release provider, version comparison and view models for a read-only check of installed applications. Git for Windows was shown as installed 2.56.0 with release 2.56.0.1 available.

No versions or update results were fabricated. No installer, uninstall, self-update, tool refresh or cleanup action ran. The animated walkthrough selects an update and navigates the wardrobe; it does not demonstrate a completed installation. Delete, Patch and Backup retain their disabled development controls. Its persistent caption says “Read-only interface demo · no updates installed”.
